# Jekyll 블로그 글 올리기

다른 사람의 블로그를 보긴 했지만 이번에 Jekyll를 활용하게 된 것은 처음이다. 글을 올리는 것에 생각보다 귀찮은 과정이 들어간다. 이걸 정리해놓고 두고두고 볼 생각이다.

이 순서는 이미 [공식 문서](https://github.com/cotes2020/jekyll-theme-chirpy/wiki)를 보고 `_config.yml`까지 수정했다는 가정 하에 작성되었다.

## 1. 문서 확인

[글 작성 법](https://chirpy.cotes.page/posts/write-a-new-post/)을 참고하였다.

[Front Matter](https://jekyllrb.com/docs/front-matter/)도 마찬가지로 알아보도록 하자.

## 2. [Jekyll-Compose](https://github.com/jekyll/jekyll-compose) 세팅하기

1. `Gemfile`의 아래 줄에 `gem 'jekyll-compose', group: [:jekyll_plugins]`을 추가한다.
2. 터미널을 열어 `bundle install`을 입력한다.
3. 만약 설치가 안되면 `sudo`를 붙여 다시 입력해본다.
4. 설치가 완료됐다면 `bundle exec jekyll help`를 입력해본다.
5. `post`나 `draft`이 보인다면 설치가 끝났다.

## 3. 글 작성

1. `bundle exec jekyll post "글 제목"`을 실행하면 자동으로 [Front Matter](https://jekyllrb.com/docs/front-matter/)와 함께 마크다운 파일이 만들어진다.
2. 마음껏 글을 작성한다.

> 초안 작성엔 `bundle exec jekyll draft "글 제목"`을 실행하여 `publish`하는 방법이 있지만 내 성격상 사용하지 않을 것 같다.

## 4. 업로드

GitHub Pages를 사용하기 때문에 그저 `git push`만 하면 된다.
